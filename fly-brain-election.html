Goal

A notebook where a teammate types a free-text description of each Thai party, and a simulated fruit-fly brain returns a probability for each party. Claude turns the text into two taste signals, the published whole-brain model (Shiu et al. 2024, FlyWire connectome) simulates the response, and the proboscis motor neuron MN9 is the vote.

What the user will see

1 notebook · 3 modules · N parties → N probabilities The notebook runs top to bottom. Each party's text becomes an appeal and an aversion score in 0–1. Appeal drives the 21 sugar-sensing neurons, aversion drives the 21 bitter-sensing neurons, both as rates up to 200 Hz. One simulation per party. MN9's firing rate is the party's score, and a softmax over scores gives the probabilities.

Task 2 — Wrap the brain model: stimulus in, MN9 rate out

Create flyvote/neurons.py with the FlyWire IDs copied from the paper's figures.ipynb, and flyvote/brain.py with the five functions below. run_party quantizes each score to a 20 Hz step so that near-identical parties share a cached parquet, and it puts n_run in exp_name so a changed trial count never reuses a stale file. The MN9 rate is counted straight from the spike parquet: the vendor utils.get_rate pivot raises KeyError on an empty result and loops in Python over every spiking neuron. The vendor import happens inside run_party, so the pure functions test without Brian2 installed.

import anthropic from pydantic import BaseModel, Field SYSTEM = """You translate a Thai political party's platform into what a fruit fly would taste. appeal = sweetness (0..1), aversion = bitterness (0..1). Score the same text the same way every time. reason: one playful sentence.""" class Traits(BaseModel): appeal: float = Field(ge=0, le=1) aversion: float = Field(ge=0, le=1) reason: str def score_party(name: str, description: str) -> Traits: if not description.strip(): raise ValueError(f"{name}: write a description first") With an empty description Claude would score the real party from its own knowledge. The team's words, or nothing. client = anthropic.Anthropic() response = client.messages.parse( model="claude-opus-5-5", max_tokens=1024, system=SYSTEM, output_config={"effort": "low"}, messages=[{"role": "user", "content": f"Party: {name}\n\n{description}"}], output_format=Traits, ) return response.parsed_output No prefill, no forced tool_choice: both return 400 on claude-opus-5-5.
